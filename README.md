## 📋 Overview

A robust, feature-rich e-commerce platform built with PHP and MySQL, designed to provide a seamless online shopping experience. This fully functional project features user-facing shopping capabilities and a secure admin panel, supporting comprehensive e-commerce operations from product browsing to order management.

The platform addresses the growing need for small to medium-sized businesses to establish their online presence with a professional, scalable, and secure e-commerce solution. It offers an intuitive shopping experience for customers while providing powerful management tools for store administrators.

Our e-commerce store stands out with its clean, responsive design, optimized performance, and comprehensive feature set including product browsing, cart management, checkout processes, and complete admin-side control.

## 🚀 Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/sayan-jagulia/ecommerce-store.git
   cd ecommerce-store
   ```

2. **Set up the database**
   - Import the database schema from `database/mystore.sql`
   - Configure database connection in `includes/connect.php`

3. **Configure web server**
   - Set up Apache/XAMPP/WAMP
   - Point document root to the project directory
   - Ensure PHP version 7.4+ is installed

4. **Start the application**
   - Access through localhost in your web browser
   - Default admin credentials will be provided separately
